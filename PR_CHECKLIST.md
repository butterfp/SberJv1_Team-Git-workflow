# Чек-лист подготовки Merge Request

## Проверка кода

- [ ] Изменения соответствуют требованиям задачи.
- [ ] В MR нет посторонних изменений.
- [ ] Код отформатирован.
- [ ] Проект успешно собирается.
- [ ] Автоматические тесты проходят.
- [ ] Статический анализатор не обнаруживает нарушений.

## Проверка Git

- [ ] Ветка имеет понятное название и содержит ID задачи.
- [ ] Сообщения коммитов информативны.
- [ ] Изменения актуальны относительно целевой ветки.
- [ ] Конфликты слияния отсутствуют.

## Оформление Merge Request

- [ ] Заголовок содержит ID задачи и краткое описание.
- [ ] Добавлено описание изменений.
- [ ] Указаны результаты тестирования.
- [ ] Добавлена ссылка на задачу.
- [ ] Ревьюеры назначены только после готовности MR.

## После ревью

- [ ] Все замечания рассмотрены.
- [ ] На исправленные замечания даны ответы.
- [ ] Получено необходимое одобрение.
- [ ] Изменения слиты автором MR.
- [ ] Неактуальные MR закрыты.
